# Images

Put original images here, one folder per type. Use the exact file names listed in
`../IMAGES.md` (any extension: .png, .jpg, .webp, .avif, .gif, .tif).

| Folder | What goes in it |
|---|---|
| `cards/` | battle cards |
| `supports/` | support cards |
| `charms/`, `relics/`, `potions/`, `materials/` | item icons |
| `currencies/` | raid currencies, scrap, Echo Marks/Cores/Keys |
| `packs/` | card packs |
| `borders/` | border examples |
| `weathers/` | weather screenshots |
| `bosses/` | boss images |
| `worlds/`, `places/`, `zones/` | area screenshots (worlds, shops/NPCs, Echo Depths zones) |
| `gamepasses/` | game pass icons |
| `frames/` | profile frames and titles |
| `routes/` | secret boss route screenshots (`<boss-id>-1`, `-2`, `-3`, `-poster`) |
| `screenshots/` | in-game menus and screens |
| `ui/` | logo and other site art |

Originals are never modified. The build creates optimised AVIF/WebP copies in `dist/img/`.
